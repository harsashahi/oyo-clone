# OYO Clone 🏨

An **under-construction OYO Rooms clone** built to practice and demonstrate full-stack web development concepts.  
This project aims to replicate core features of the OYO hotel booking platform, including UI layout, room listings, and booking flow.

> ⚠️ **Status:** Under Development

---

## 🚀 Project Overview

This project is a learning-focused clone of the OYO platform.  
It is being developed incrementally, starting from frontend structure and moving toward backend integration.

---

## ✨ Features (Planned & In Progress)

- 🏠 Home page with hotel listings  
- 🔍 Search & filter hotels  
- 🛏️ Room details page  
- 📅 Booking flow (UI first)  
- 👤 User authentication (planned)  
- 💳 Payment integration (future scope)

---
